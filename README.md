## Featured Work

### 🧠 Efficient Language Models for Human Activity Recognition
My MSc research explores adapting pretrained language-model backbones to wearable IMU signals for cross-dataset human activity recognition, with an emphasis on parameter efficiency and context-aware modeling.

- Evaluated across multiple public HAR datasets using a leave-one-dataset-out setup.
- Explored sensor patching, cross-attention-based reprogramming, alignment pretraining, and reconstruction objectives.
- Research work is **under consideration and not yet published**.

[Explore the llm-har repository](https://github.com/Shehroz-Mir/llm-har)
